# organization-scaner

CLI-проект на TypeScript для чтения Excel-файлов и поиска данных на Яндекс.Картах через Puppeteer.

## Установка

```bash
npm install
```

## Команды

```bash
npm run build
npm start -- "D:\VS Code\cadastr\1.xlsx" xlsx 4 2 5
npm run dev -- "D:\VS Code\cadastr\1.xlsx" xlsx 4 2 5
```

После сборки CLI можно запустить напрямую:

```bash
node dist/index.js "D:\VS Code\cadastr\1.xlsx" xlsx 4 2 5
```

Готовый exe-файл запускается так:

```bash
ya-finder.exe "D:\VS Code\cadastr\1.xlsx" xlsx 4 2 5
```

Формат аргументов: `<путь-к-файлу.xlsx> <выходная-директория> <номер-колонки> <номер-строки> <дополнительная-колонка>`.

`--column` использует нумерацию с 1: `1` означает колонку A, `2` означает колонку B.
Номер строки тоже начинается с 1: `2` означает начать обработку со второй строки.
Дополнительная колонка необязательна, по умолчанию `0`, то есть значение не берётся.

Приложение читает значения из указанной колонки первого листа Excel-файла и передаёт каждое непустое значение в асинхронный метод `parse`. Сейчас `parse` открывает `https://yandex.ru/maps/`, ищет переданное значение и возвращает найденные названия из списка результатов.

Результат сохраняется в файл `result.xlsx` в выходной директории. Для каждого адреса создаётся отдельная таблица с границами: заголовок объединяет три колонки и содержит адрес, ниже в первой колонке идут найденные организации, во второй объединённой по высоте колонке указано их количество, в третьей объединённой колонке указано значение из дополнительной колонки исходного файла.

## Строгая типизация

TypeScript настроен в strict-режиме через `tsconfig.json`.
